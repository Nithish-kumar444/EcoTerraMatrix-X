# ECOTERRAMATRIXX

## Global Climate Intelligence Matrix  
### AI-Powered Carbon Emission Analytics & Forecasting Platform

ECOTERRAMATRIXX is an advanced climate intelligence dashboard built using Streamlit and Plotly.  
It provides interactive visualization, carbon emission analytics, renewable energy insights, and AI-powered forecasting tools to support data-driven environmental decision-making.

---

## Features

### Global Emission Dashboard
- Real-time CO₂ emission visualization
- Continent-level emission share gauge
- Interactive world emission heatmap

### Advanced Analytics
- Continent-wise emission comparison
- Renewable Energy vs CO₂ analysis
- Cumulative CO₂ emissions over time

EcoTerraMatrix-X: Carbon Estimation & Analysis DashboardEcoTerraMatrix-X is an advanced analytics platform designed to track global $CO_2$ emissions and provide personalized carbon footprint calculations. The application leverages machine learning and computer vision to offer actionable environmental insights.+4
🚀 Deployment OverviewThe application is built using Streamlit and is configured to be shared via a secure ngrok tunnel for remote access.🧠 Machine Learning ModelsRandom Forest Regressor: Powering the multi-sector carbon calculators (Individual, Transport, Industry, and Scope 3) to predict emission values based on user input features.+4
Convolutional Neural Network (CNN): Utilized for the Carbon Emission Classifier, which analyzes uploaded images of cityscapes or skies to predict pollution levels and environmental degradation.+2
